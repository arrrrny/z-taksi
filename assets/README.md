# Z-Taksi Assets

This directory contains app assets like images and icons.

## Directory Structure

- `images/` - App images (logos, illustrations, etc.)
- `icons/` - Custom icons used in the app

## Adding Assets

When adding new assets:

1. Place files in the appropriate subdirectory
2. Update `pubspec.yaml` if needed
3. Use consistent naming (lowercase with underscores)

## Image Guidelines

- Use appropriate formats (PNG for images with transparency, JPG for photos)
- Provide multiple resolutions for different screen densities when needed
- Optimize images to reduce app size
